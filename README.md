# 梅花易数 · 排盘断卦

在线使用：**https://3253778505-bot.github.io/meihua-yishu/**

一个可离线使用的梅花易数排盘与断卦工具。依《增广校正梅花易数》（宋·邵雍撰，九州出版社 2007 年版）整理起卦法、体用总诀、十八占、八卦万物类占与观梅诸例，纯原生 HTML / CSS / JavaScript，无构建、无后端。

## 功能

- 时间起卦：农历年支数 + 月 + 日取上卦，再加时辰取下卦，总数取动爻；自动换算农历、干支、时辰、节气月建。
- 数字起卦、字占、手动排卦；浏览器不支持农历时可手动填写农历年月日时。
- 本卦、互卦、变卦三盘并列，标注体用、动爻、五行；附错卦、综卦。
- 自动断卦：体用生克、月令旺衰、互卦过程、变卦终局、应期推演、占类类象。
- 八卦万物类象、观梅诸例复原、断诀备查、本地记录、打印、分享链接。

## 安装到手机

用手机浏览器打开上面的网址：

- Android Chrome：菜单 → 安装应用 / 添加到主屏幕；
- iPhone Safari：分享 → 添加到主屏幕。

首次联网打开后会缓存全部文件，之后断网也能用。
