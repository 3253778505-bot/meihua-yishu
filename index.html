观梅卦例

依《增广校正梅花易数》卷一、卷四所载占例复原；每例皆可回填卦盘，对照体用生克与应期。

断卦要诀

起卦、体用、旺衰、互变、应期——梅花易数断卦的次第，尽在于此。

关于此器

一个可以离线使用的梅花易数排盘与断卦工具。

用法

  1. 起卦：时间起卦最常用——以农历年支数、月、日之和取上卦，再加时辰数取下卦，总数取动爻。也可报数、写字，或直接指定上下卦与动爻。
  2. 看盘：本卦为事之体，互卦为事之中，变卦为事之终。动爻所在之卦为「用」，另一卦为「体」。
  3. 断卦：先看体用生克定吉凶，再以月令旺衰定力量，参互卦看过程、变卦看结局，最后以成卦之数与用卦五行定应期。
  4. 存证：点「存记录」可留存卦盘；「复制断语」生成可分享的文字；「打印」输出干净的排盘单。

体例

卦辞、大象取自《周易》；起卦法、体用总诀、十八占、八卦万物类占、占例原文，均据九州出版社《增广校正梅花易数》（宋·邵雍撰，李一忻点校，郑同增订，2007 年）整理，个别明显讹字依通行本校正。

农历换算使用浏览器内置的中国历（Intl Chinese calendar），节气月建以近似日期推算，交节前后一日可能有一日之差，可在断卦时自行参酌。

梅花易数重在「象」与「理」，此器所出断语为依规则推演之参考，并非宿命判决。占者当以事理为归，不可执数而忘理。

在别的设备上使用

单文件版：dist/梅花易数.html 把 CSS、JS 全部内联在一个文件里，拷到 U 盘、发到手机或另一台电脑，用浏览器打开即可，断网也能用。

局域网：在本机运行 python -m http.server 8848 --bind 0.0.0.0，手机连同一 Wi-Fi，访问 http://电脑IP:8848，iPhone 与 Android 都稳。

托管 / 安装：把整个目录（或 dist/梅花易数-网站版.zip）传到 GitHub Pages、Netlify、Vercel 等静态托管；HTTPS 下可在手机浏览器「添加到主屏幕」，像 App 一样离线打开。
